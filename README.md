# 弦轴锥度配合系统 - 传统制琴工艺

面向小提琴等弓弦乐器制作的弦轴配合生产力系统，基于摩擦自锁原理，实现弦轴锥度与孔配合的精确计算与管理。

## 功能特性

### 📏 弦轴录入页
- 录入弦轴箱孔的锥度、弦轴材质与弦的张力
- 实时计算弦轴锥度和孔锥度
- 自动检测参数偏差并标红显示
- 历史记录管理

### ⚙️ 锥度配合页
- 按摩擦自锁原理计算弦轴锥度与孔的配合
- 识别配合过紧难转或过松打滑的偏差并标红
- 自锁条件验证（锥度半角 < 摩擦角/1.5）
- 同轴度校验，避免别劲
- 配合修整方案生成
- 按弦张力反推弦轴锥度参数

### 🎵 调音稳定页
- 计算弦轴在弦张力下的扭矩与握持稳定
- 扭矩分析：T = F·r·sin(θ)
- 握持稳定性评估与可视化
- 湿度变化对木质弦轴与孔配合的胀缩影响模拟
- 20%-80% 湿度范围配合变化可视化

### 📁 工艺档案页
- 记录每件乐器的弦轴配合，建立工艺档案
- 关联弦轴记录到对应乐器
- 维护历史记录管理
- 整体状态评估与风险预警

### 📚 工艺库页
- 存储不同乐器的弦轴方案为工艺库
- 内置小提琴标准弦轴方案
- 支持按乐器类型筛选
- 创建自定义方案
- 方案参数一键复制

### ⚠️ 风险预警系统
- 配合过松调音回滑跑音的风险预警
- 同轴度偏差过大别劲风险预警
- 湿度变化影响风险预警
- 锥度过大不满足自锁条件预警
- 预警分级：低/中/高/严重

## 核心计算原理

### 摩擦自锁原理
锥度半角 α 必须小于摩擦角 φ 除以安全系数 (1.5)：
```
α < φ / 1.5
其中：φ = arctan(μ)，μ 为摩擦系数
```

### 锥度计算
```
锥度 = (大头直径 - 小头直径) / 长度
```

### 扭矩计算
```
T = F · r · sin(θ)
其中：F 为弦张力，r 为弦轴半径，θ 为包角
```

### 握持稳定性
```
握持稳定性 = (最大摩擦力 / 弦张力) × 100%
```

### 湿度胀缩模拟
```
直径变化 = 初始直径 × 胀缩系数 × 湿度变化量
配合变化 = 弦轴直径变化 - 孔直径变化
```

## 数据库

系统使用 NeDB 嵌入式数据库，数据存储在用户数据目录：
- Windows: `%APPDATA%\peg-taper-system\databases\`
- macOS: `~/Library/Application Support/peg-taper-system/databases/`
- Linux: `~/.config/peg-taper-system/databases/`

包含三个数据集合：
1. `pegs.db` - 弦轴记录
2. `archives.db` - 工艺档案
3. `library.db` - 工艺库

## 标准工艺参数

### 小提琴 4/4 弦轴标准
- **推荐锥度**: 1:30 (0.0333)
- **弦轴直径**: 小头 7.8mm，大头 8.6mm，长度 24mm
- **最佳过盈量**: 0.02-0.06mm
- **同轴度公差**: ≤ 0.05mm
- **推荐材质**: 乌木 (摩擦系数 0.45)

### 弦张力参考 (4/4 小提琴)
- G弦: 35N
- D弦: 32N
- A弦: 30N
- E弦: 28N

### 最佳环境湿度
- 40% - 50% RH

## 最佳实践

1. **测量精度**: 使用千分尺测量直径，精度至少 0.001mm
2. **锥度一致性**: 弦轴与孔的锥度差应小于 0.002
3. **环境控制**: 建议在恒湿环境 (45% RH) 下进行配合
4. **定期检查**: 季节交替时检查配合状态
5. **档案记录**: 每件乐器都应建立完整的工艺档案
